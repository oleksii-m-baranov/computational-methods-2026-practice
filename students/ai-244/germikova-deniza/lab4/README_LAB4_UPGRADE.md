# ЛР4 — додаткова діагностична серія main1500

Серія `main1500` містить дев’ять прогонів (`none`, `trim`, `trim+state` по три повтори) за порога `COMPRESS_AT=1500`. Основна серія `main` виконана за порога 2150. Результати серій наведені окремо в [звіті](report.md).

## Відтворення

Потрібні Python, Ollama з моделлю `qwen25-3k`, залежності `openai`, `pydantic`, `python-dotenv`, `langfuse` та локальні налаштування Langfuse. З каталогу `lab4`:

```bash
python3 lab4_run_main1500.py
```

Скрипт змінює поріг лише в пам’яті процесу та пропускає вже завершені прогони. Журнали збережено в `logs/main1500_*.log`; аналіз окремого журналу: `python3 analyze.py logs/main1500_trim+state_r1.log`.

`lab4_upgrade_prepare.py`, `lab4_upgrade_finalize.py` — допоміжні утиліти підготовки звіту та архівування результатів. Індексів, результатів основної серії та конфігурації агента вони не змінюють. Файл `.env` з локальними ключами не входить до репозиторію.
