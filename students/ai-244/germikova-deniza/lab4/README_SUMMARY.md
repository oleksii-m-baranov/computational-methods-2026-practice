# ЛР4 — підсумовування замість обрізання

Режим `summary` реалізовано у `summary.py`, `compress.py` та `measure.py`. Основне вимірювання `all` включає три конфігурації: `none`, `trim`, `trim+state`. Підсумовування досліджено в окремих серіях `extra` (поріг 2150) та `extra1500` (поріг 1500).

## Відтворення

З каталогу `lab4`, в активованому середовищі з потрібними залежностями та запущеним Ollama:

```bash
python3 lab4_extra_run.py summary 3 extra
python3 lab4_extra_run.py trim 3 extra1500 1500
python3 lab4_extra_run.py summary 3 extra1500 1500
python3 lab4_summary_review.py extra1500
```

Перед повторним вимірюванням необхідно зберегти копію журналів відповідної серії. Результати `summary` за порога 2150 та порівняння `trim` і `summary` за порога 1500 описано в [report.md](report.md). Окремо враховано токени підсумовування та втрату числової інформації в переказі. Первинні журнали містяться в `logs/extra*.log`.
