## Експерименти

По-перше, виконайте точно команду додаткового завдання методички — три повтори за **основним порогом 2150**:

```bash
python3 lab4_extra_run.py summary 3 extra
```

У попередніх основних запусках агент закінчував при 2059 токенах, тому `summary` **може не активуватися** за 2150; це варто чесно відобразити в звіті.

Щоб отримати **реальні перекази і коректне порівняння**, у двох окремих серіях знизьте поріг **тільки в оперативній пам'яті до 1500** та повторіть обидва режими (по три прогони). Файл `config.py` не зміниться:

```bash
python3 lab4_extra_run.py trim 3 extra1500 1500
python3 lab4_extra_run.py summary 3 extra1500 1500
python3 lab4_summary_review.py extra1500
```

Обов'язково перевіряйте блок `ПІДСУМОК ІСТОРІЇ` проти реальних рядків `результат:` (у моделі можливе спотворення цифр). Порівнюйте медіани `prompt_tokens` та окремо враховуйте токени додаткового виклику summarization. Ця серія — **додаткова діагностика**, а не заміна `main`.

Результати не додаються у `report.md` автоматично: потрібні справжні логи. Після запуску використайте цифри з `lab4_summary_review.py` для додаткової таблиці й розділу в звіті.

**Не додавати `.env`, ключі Langfuse, `backup_before_*`, `__pycache__` в архів викладачеві.**
