# Навчальні дані
Рецепти й числові значення згенеровані чат-ботом для навчального проєкту та є вигаданими.
12 рецептів; 19 рядків у довіднику; дві схожі назви: «Плов з куркою» і «Плов овочевий».
Лимон згадується в рецепті, але відсутній у довіднику. Для солі ціна дорівнює нулю.
Страв із тунцем немає. Для калорійності рису в цьому наборі використано 344 ккал на 100 г.
