### Правильний виклик (контроль)
виклик : calc_installment({"price": 24000, "months": 6, "overpay_percent": 10})
рівень : ok
текст  : 4400.0 грн на місяць, усього 26400.0 грн

### Зламаний JSON
виклик : laptop_info({"model": "StudyBook 14")
рівень : syntax
текст  : Помилка: аргументи не пройшли перевірку.
Поле JSON: Invalid JSON: EOF while parsing an object at line 1 column 24
Виправ аргументи і виклич інструмент ще раз.

### Неіснуючий інструмент
виклик : reserve_laptop({"model": "StudyBook 14"})
рівень : name
текст  : Помилка: інструмента 'reserve_laptop' не існує. Доступні: search_laptops, laptop_info, calc_installment. Виклич один з доступних або повідом користувачу, що такої дії немає.

### Заборонена дія
виклик : place_order({"model": "StudyBook 14"})
рівень : permission
текст  : Помилка: інструмент 'place_order' недоступний. Не повторюй виклик, повідом користувачу, що ця дія недоступна.

### Значення немає в довіднику
виклик : laptop_info({"model": "MacBook Pro 16"})
рівень : meaning
текст  : Помилка: моделі 'MacBook Pro 16' немає в довіднику. Точну назву моделі можна дізнатися через search_laptops. Виправ назву або повідом користувачу, що такої моделі немає.

### Схожа назва (підказка)
виклик : laptop_info({"model": "StudyBook 15"})
рівень : meaning
текст  : Помилка: моделі 'StudyBook 15' немає в довіднику. Можливо, мається на увазі: StudyBook 14. Точну назву моделі можна дізнатися через search_laptops. Виправ назву або повідом користувачу, що такої моделі немає.

### Модель є в корпусі, але не в довіднику
