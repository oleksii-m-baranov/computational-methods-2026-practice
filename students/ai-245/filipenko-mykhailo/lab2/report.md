## 5. Реалізація інструментів

У файлі `tools.py` реалізовано три функції.

### Таблиця 3 — Інструменти агента

| Інструмент | Аргументи | Призначення |
|---|---|---|
| search_laptops | query | Пошук моделей за призначенням |
| laptop_info | model | Отримання ціни, наявності та гарантії |
| calc_installment | price, months, overpay_percent | Розрахунок розстрочки |

### Опис інструментів для мовної моделі

У файлі `schemas.py` було створено три описи інструментів.

**search_laptops**

Інструмент використовується, коли користувач описує призначення ноутбука, але не називає конкретну модель. Аргумент `query` повинен містити короткий текстовий запит українською мовою.

**laptop_info**

Інструмент використовується після вибору конкретної моделі. Він повертає її ціну, кількість на складі та гарантійний термін.

**calc_installment**

Інструмент використовується для розрахунку розстрочки. Ціна повинна бути отримана через `laptop_info`. Самостійно виконувати обчислення модель не повинна.

## 6. Програмний код SCHEMAS

Під час виконання лабораторної роботи я створив файл `schemas.py`, у якому описав інструменти AI-консультанта.

Для кожного інструмента вказав назву, призначення, типи параметрів та обов'язкові аргументи.

Нижче наведено повний код `SCHEMAS`.

```python
"""Описи інструментів AI-консультанта. Варіант 9."""

SCHEMAS = [
    {
        "type": "function",
        "function": {
            "name": "search_laptops",
            "description": (
                "Шукає ноутбуки за призначенням або характеристикою "
                "та повертає назви знайдених моделей одним рядком. "
                "ЗАВЖДИ викликай цей інструмент, якщо користувач "
                "описує призначення ноутбука, але не називає модель. "
                "Передавай коротке ключове слово українською. "
                "Наприклад: навчання, програмування, ігри, дизайн, офіс. "
                "Аргумент query повинен бути РЯДКОМ, а НЕ списком."
            ),
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {
                        "type": "string",
                        "description": (
                            "Одне-два слова українською у вигляді "
                            "звичайного текстового рядка. "
                            "Правильно: \"навчання\". "
                            "Неправильно: [\"навчання\"]. "
                            "Не передавай повне питання користувача."
                        )
                    }
                },
                "required": ["query"],
                "additionalProperties": False
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "laptop_info",
            "description": (
                "Шукає конкретну модель ноутбука в CSV-довіднику "
                "та повертає ціну, кількість на складі й гарантію. "
                "Викликай після search_laptops, коли вже відома "
                "точна назва моделі. "
                "Обов'язково використовуй цей інструмент, якщо "
                "користувач запитує ціну або наявність. "
                "Не вигадуй ціну чи кількість товару."
            ),
            "parameters": {
                "type": "object",
                "properties": {
                    "model": {
                        "type": "string",
                        "description": (
                            "Точна назва ОДНІЄЇ моделі, отримана "
                            "з результату search_laptops. "
                            "Наприклад: \"StudyNova 14\". "
                            "Передавай рядок, не список моделей."
                        )
                    }
                },
                "required": ["model"],
                "additionalProperties": False
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "calc_installment",
            "description": (
                "Обчислює щомісячний платіж та загальну суму "
                "при купівлі ноутбука в розстрочку. "
                "ЗАВЖДИ використовуй для розрахунку розстрочки. "
                "Спочатку знайди ноутбук через search_laptops, "
                "потім отримай ціну через laptop_info, "
                "і лише після цього викликай calc_installment. "

                "type": "object",
                "properties": {
                    "price": {
                        "type": "number",

                            "отримана з результату laptop_info."
                        )
                    },
                    "months": {
                        "type": "number",

                            "Кількість місяців розстрочки. "

                        )
                    },
                    "overpay_percent": {

                        )

                },

                    "price",
                    "months",
                    "overpay_percent"
                ],
                "additionalProperties": False
            }
        }

```

### Пояснення коду SCHEMAS

У списку `SCHEMAS` описано три функції, які мовна модель може використовувати для виконання запитів.

Поле `type` визначає тип інструмента, `name` містить його назву, `description` пояснює призначення, а `parameters` описує структуру аргументів.

Поле `required` визначає обов'язкові параметри. За допомогою `additionalProperties: False` забороняється передавання додаткових аргументів, які не описані в схемі.

Наприклад, якщо користувач хоче придбати ноутбук у розстрочку, правильна послідовність викликів має бути такою:

```text
search_laptops
      |
      v
laptop_info
      |
      v
calc_installment
      |
      v
Відповідь користувачу
```

Використання схем дозволяє визначити, яку функцію потрібно викликати та які дані передати.

## 11. Детальний розбір провалу Z3

**Запит користувача:**

Порадь ноутбук для навчання і скажи, скільки платити на місяць при розстрочці на 6 місяців з переплатою 10%.

**Очікувана поведінка:**

Агент повинен знайти модель, отримати її ціну та викликати калькулятор розстрочки.

**Фактичний фрагмент логу останнього прогону:**

```text
============================================================
ЗАДАЧА: Порадь ноутбук для навчання і скажи, скільки
платити на місяць при розстрочці на 6 місяців
з переплатою 10%

--- крок 1 | prompt_tokens=1079
  виклик   : search_laptops({"query":"навчання"})
  результат: StudyNova 14 | StudyNova 15

--- крок 2 | prompt_tokens=1132
  виклик   : laptop_info({"model":"StudyNova 14"})
  результат: Ціна: 22000 грн, на складі: 5 шт.,
             гарантія: 24 міс.

--- крок 3 | prompt_tokens=1232
ВІДПОВІДЬ: Знайдений вами ноутбук - StudyNova 14.
Ціна одного ноутбука становить 22000 грн.
На складі 5 таких моделей, і гарантія на 24 місяці.
Тепер я обчислюю платіж за розстрочку на 6 місяців
з переплатою 10%.
```

**Аналіз помилки:**

Модель правильно виконала пошук і отримала ціну ноутбука, але не викликала `calc_installment`.

Замість розрахунку вона завершила відповідь повідомленням про намір обчислити платіж.

На мою думку, це сталося через передчасне завершення роботи агента. Модель не продовжила ланцюжок інструментів, хоча для відповіді ще бракувало результату калькулятора.

Під час окремого тестування цей ланцюжок працював правильно:

```text
search_laptops → laptop_info → calc_installment
```

Для StudyNova 14 результат калькулятора становив:

| Показник | Значення |
|---|---:|
| Ціна | 22000 грн |
| Термін | 6 місяців |
| Переплата | 10% |
| Щомісячний платіж | 4033.33 грн |
| Загальна сума | 24200 грн |

Це підтверджує, що проблема полягала не у функції калькулятора, а в рішенні мовної моделі не викликати її.
