Мистецтво швидкого сортування: від вибору до злиття
Технічна література, складний рівень
Практичне керівництво фокусується на глибинному аналізі класичних та сучасних алгоритмів упорядкування даних. Автор детально розбирає часову складність, роботу з пам’яттю та оптимізацію коду для високонавантажених систем. Видання містить приклади реалізації мовами C++ та Rust із детальним профілюванням.
