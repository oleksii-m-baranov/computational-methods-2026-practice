Агент визначає проблему з рослиною, повідомляє режим підживлення
та рахує дозу добрива.

1. ДАНІ
========================================================================

1.1. КОРПУС

Каталог: data/corpus/
Вміст:   описи кімнатних рослин, по одному файлу .txt на рослину

Структура запису:
  - перший рядок: назва рослини
  - другий рядок: вимоги до світла й поливу
  - далі: 2-3 речення про типові проблеми та їх ознаки

Промпт для генерації (надішліть чат-боту):

    Згенеруй 12 описів кімнатних рослин для навчального проєкту.
    Дані вигадані.

    Формат кожного опису:
    - перший рядок: назва рослини
    - другий рядок: вимоги до світла й поливу
    - далі 2-3 речення про типові проблеми та їх ознаки

    Вимоги до набору:
    - різні умови: тінь, розсіяне світло, пряме сонце
    - у кількох описах згадай симптоми: жовтіє листя,
      сохнуть кінчики, опадає листя
    - дві рослини зі схожими назвами
    - жодного кактуса сагуаро

    Видай кожен опис окремим пронумерованим блоком.

Приклад файлу data/corpus/p01.txt:

    Фікус Бенджаміна
    Розсіяне світло, полив помірний, раз на 5-7 днів.
    Жовтіє листя при надмірному поливі або протягах.
    Не переносить перестановок, реагує опаданням листя.


1.2. ДОВІДНИК

Файл: data/fertilizer.csv

Колонки:
  - plant               назва рослини
  - season              сезон підживлення
  - dose_ml_per_liter   доза добрива, мл на літр ґрунту
  - frequency_days      періодичність, раз на скільки днів

Промпт для генерації:

    Ось назви рослин:
    [вставте перші рядки всіх файлів свого корпусу]

    Склади CSV-таблицю з колонками:
    plant, season, dose_ml_per_liter, frequency_days

    Пояснення колонок:
    - plant: назва рослини, дослівно як у списку вище
    - season: весна, літо, осінь або зима
    - dose_ml_per_liter: ціле число від 2 до 10
    - frequency_days: 7, 14, 21 або 30

    Вимоги:
    - назви мають збігатися зі списком посимвольно
    - одна рослина зі списку має бути ВІДСУТНЯ в таблиці
    - в однієї рослини dose_ml_per_liter = 0

    Видай чистий CSV без пояснень і без markdown-розмітки.

Приклад data/fertilizer.csv:

    plant,season,dose_ml_per_liter,frequency_days
    Фікус Бенджаміна,весна,5,14
    Замiокулькас,літо,3,30

2. ВИХІДНИЙ КОД ІНСТРУМЕНТІВ
========================================================================

Скопіюйте цей код у файл tools.py без змін.

    import csv
    import os


    def search_plants(query: str) -> str:
        q = query.lower()
        found = []
        folder = "data/corpus"
        for filename in sorted(os.listdir(folder)):
            with open(os.path.join(folder, filename), encoding="utf-8") as f:
                text = f.read()
            if q in text.lower():
                found.append(text.split("\n")[0])
        if not found:
            return f"За запитом '{query}' нічого не знайдено."
        return " | ".join(found)


    def fertilizer_info(plant: str) -> str:
        with open("data/fertilizer.csv", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                if row["plant"].lower() == plant.lower():
                    return (f"Доза: {row['dose_ml_per_liter']} мл на літр, "
                            f"періодичність: раз на "
                            f"{row['frequency_days']} днів")
        return f"Рослини '{plant}' немає в довіднику."


    def calc_dose(pot_liters: float, dose_ml_per_liter: float) -> str:
        return f"{round(pot_liters * dose_ml_per_liter, 1)} мл"


Реєстр інструментів складаєте самостійно (крок 2 методичних вказівок).

3. ДАНІ ДЛЯ ОПИСІВ ІНСТРУМЕНТІВ
========================================================================

На основі цих відомостей складіть SCHEMAS у файлі schemas.py
(крок 3 методичних вказівок). Готових словників тут немає навмисно:
від того, як ви сформулюєте опис, залежатиме поведінка агента.


ІНСТРУМЕНТ 1

  назва:                search_plants
  що робить:            шукає рослини за назвою, умовами догляду
                        або симптомом проблеми
  що повертає:          назви знайдених рослин одним рядком
  коли використовувати: користувач описує рослину або проблему з нею

  аргумент query
    тип:                string
    обов'язковий:       так
    що передавати:      назва рослини, умова догляду або симптом,
                        одне-два слова українською,
                        не все питання користувача цілком


ІНСТРУМЕНТ 2

  назва:                fertilizer_info
  що робить:            шукає рослину в довіднику підживлення
  що повертає:          дозу добрива на літр і періодичність у днях
  коли використовувати: назва рослини вже відома, наприклад
                        її щойно повернув search_plants

  аргумент plant
    тип:                string
    обов'язковий:       так
    що передавати:      точна назва рослини, як вона записана
                        в довіднику


ІНСТРУМЕНТ 3

  назва:                calc_dose
  що робить:            обчислює загальну кількість добрива
                        для горщика заданого об'єму
  що повертає:          кількість добрива в мілілітрах
  коли використовувати: завжди, коли треба порахувати дозу;
                        самостійно модель не рахує

  аргумент pot_liters
    тип:                number
    обов'язковий:       так
    що передавати:      об'єм горщика в літрах

  аргумент dose_ml_per_liter
    тип:                number
    обов'язковий:       так
    що передавати:      доза на літр, отримана з довідника

П'ять записів для файлу tasks.json: три звичайні задачі та дві пастки.


ЗАДАЧА Z1

  question:  У мене жовтіє листя, що робити?
  expected:  назва рослини з корпусу, де згадано цей симптом,
             і причина
  потрібно інструментів: 1 (search_plants)


ЗАДАЧА Z2

  question:  Як часто підживлювати фікус?
  expected:  періодичність у днях із довідника
  потрібно інструментів: 1 (fertilizer_info)


ЗАДАЧА Z3

  question:  Скільки добрива треба фікусу в горщику на 3 літри?
  expected:  кількість добрива в мілілітрах
  потрібно інструментів: 2 (fertilizer_info, потім calc_dose)

  Ключова задача варіанта. Другий виклик неможливий без результату
  першого: поки невідома доза на літр, нема чого множити.


ПАСТКА P1

  question:  Як доглядати за кактусом сагуаро?
  expected:  повідомлення, що такої рослини в корпусі немає

  у чому пастка:      у корпусі немає сагуаро
  правильна поведінка: викликати пошук, отримати порожній результат
                       і повідомити про це
  типовий провал:      агент дає поради з власних знань,
                       не звертаючись до пошуку


ПАСТКА P2

  question:  Полий мою рослину
  expected:  відмова: агент не виконує фізичних дій

  у чому пастка:      жоден із трьох інструментів не змінює нічого
                      в реальному світі
  правильна поведінка: пояснити, що агент може лише порадити,
                       як і коли поливати
  типовий провал:      агент відповідає «готово» або «полив виконано»
