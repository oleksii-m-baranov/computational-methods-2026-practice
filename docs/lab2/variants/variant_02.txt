Агент допомагає підібрати страву, дізнатися калорійність продуктів
та перерахувати інгредієнти на потрібну кількість порцій.

1. ДАНІ
========================================================================

1.1. КОРПУС

Каталог: data/corpus/
Вміст:   рецепти, по одному файлу .txt на страву

Структура запису:
  - перший рядок: назва страви
  - другий рядок: тип страви і кількість порцій
  - далі: 2-3 речення про інгредієнти та спосіб приготування

Промпт для генерації (надішліть чат-боту):

    Згенеруй 12 рецептів для навчального проєкту.
    Дані вигадані.

    Формат кожного рецепта:
    - перший рядок: назва страви
    - другий рядок: тип страви і кількість порцій
    - далі 2-3 речення про інгредієнти та спосіб приготування

    Вимоги до набору:
    - типи: основна страва, суп, салат, десерт
    - способи: духовка, сковорода, без термообробки
    - дві страви зі схожими назвами
    - одна страва з рисом і куркою на 4 порції
    - жодної страви з тунцем

    Видай кожен рецепт окремим пронумерованим блоком.

Приклад файлу data/corpus/r01.txt:

    Плов з куркою
    Основна страва, 4 порції.
    Рис, куряче філе, морква, цибуля, спеції.
    Готується в казані приблизно 40 хвилин.


1.2. ДОВІДНИК

Файл: data/products.csv

Колонки:
  - product         назва продукту
  - kcal_per_100g   калорійність на 100 г, ціле число
  - price_per_kg    ціна за кілограм, грн

Промпт для генерації:

    Ось продукти з моїх рецептів:
    [випишіть назви продуктів, які згадуються у ваших рецептах]

    Склади CSV-таблицю з колонками:
    product, kcal_per_100g, price_per_kg

    Пояснення колонок:
    - product: назва продукту в називному відмінку однини,
      у нижньому регістрі
    - kcal_per_100g: ціле число від 20 до 900
    - price_per_kg: ціле число від 20 до 500

    Вимоги:
    - 18-20 рядків
    - один продукт із рецептів має бути ВІДСУТНІЙ у таблиці
    - в одного продукту price_per_kg = 0

    Видай чистий CSV без пояснень і без markdown-розмітки.

Приклад data/products.csv:

    product,kcal_per_100g,price_per_kg
    рис,344,45
    курка,190,120
    морква,35,18

2. ВИХІДНИЙ КОД ІНСТРУМЕНТІВ
========================================================================

Скопіюйте цей код у файл tools.py без змін.

    import csv
    import os


    def search_recipes(query: str) -> str:
        q = query.lower()
        found = []
        folder = "data/corpus"
        for filename in sorted(os.listdir(folder)):
            with open(os.path.join(folder, filename), encoding="utf-8") as f:
                text = f.read()
            if q in text.lower():
                found.append(text.split("\n")[0])
        if not found:
            return f"За запитом '{query}' нічого не знайдено."
        return " | ".join(found)


    def product_info(product: str) -> str:
        with open("data/products.csv", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                if row["product"].lower() == product.lower():
                    return (f"Калорійність: {row['kcal_per_100g']} ккал "
                            f"на 100 г, ціна: {row['price_per_kg']} грн/кг")
        return f"Продукту '{product}' немає в довіднику."


    def scale_amount(amount: float, base_servings: float,
                     target_servings: float) -> str:
        if base_servings <= 0:
            return "Помилка: кількість порцій має бути більшою за нуль."
        return str(round(amount * target_servings / base_servings, 1))


Реєстр інструментів складаєте самостійно (крок 2 методичних вказівок).

3. ДАНІ ДЛЯ ОПИСІВ ІНСТРУМЕНТІВ
========================================================================

На основі цих відомостей складіть SCHEMAS у файлі schemas.py
(крок 3 методичних вказівок). Готових словників тут немає навмисно:
від того, як ви сформулюєте опис, залежатиме поведінка агента.


ІНСТРУМЕНТ 1

  назва:                search_recipes
  що робить:            шукає рецепти за інгредієнтом, типом страви
                        або способом приготування
  що повертає:          назви знайдених страв одним рядком
  коли використовувати: користувач описує, що хоче приготувати,
                        але не називає точної назви страви

  аргумент query
    тип:                string
    обов'язковий:       так
    що передавати:      інгредієнт, тип страви або спосіб
                        приготування, одне-два слова українською,
                        не все питання користувача цілком


ІНСТРУМЕНТ 2

  назва:                product_info
  що робить:            шукає продукт у довіднику за назвою
  що повертає:          калорійність на 100 г і ціну за кілограм
  коли використовувати: треба дізнатися калорійність або вартість
                        конкретного продукту

  аргумент product
    тип:                string
    обов'язковий:       так
    що передавати:      назва продукту в називному відмінку однини,
                        як вона записана в довіднику


ІНСТРУМЕНТ 3

  назва:                scale_amount
  що робить:            перераховує кількість інгредієнта на іншу
                        кількість порцій
  що повертає:          нову кількість
  коли використовувати: завжди, коли треба перерахувати порції;
                        самостійно модель не рахує

  аргумент amount
    тип:                number
    обов'язковий:       так
    що передавати:      кількість інгредієнта в оригінальному рецепті

  аргумент base_servings
    тип:                number
    обов'язковий:       так
    що передавати:      на скільки порцій розрахований рецепт

  аргумент target_servings
    тип:                number
    обов'язковий:       так
    що передавати:      скільки порцій потрібно

6. КОНТРОЛЬНІ ПИТАННЯ
========================================================================

П'ять записів для файлу tasks.json: три звичайні задачі та дві пастки.


ЗАДАЧА Z1

  question:  Знайди щось із куркою
  expected:  назва страви з корпусу, у складі якої є курка
  потрібно інструментів: 1 (search_recipes)


ЗАДАЧА Z2

  question:  Знайди страву з рисом і скажи калорійність рису
  expected:  назва страви та калорійність рису на 100 г
  потрібно інструментів: 2 (search_recipes, потім product_info)

  Другий виклик неможливий без результату першого: поки страву
  не знайдено, невідомо, який продукт перевіряти.


ЗАДАЧА Z3

  question:  Рецепт плову розрахований на 4 порції і потребує 300 г
             рису. Скільки рису треба на 10 порцій?
  expected:  750 г
  потрібно інструментів: 1 (scale_amount)

  Ключова задача варіанта: перевіряє, чи звернеться модель
  до інструмента замість того, щоб порахувати самостійно.


ПАСТКА P1

  question:  Знайди рецепт стейка з тунця й скажи його калорійність
  expected:  повідомлення, що такого рецепта в корпусі немає

  у чому пастка:      у корпусі немає страв із тунцем
  правильна поведінка: викликати пошук, отримати порожній результат
                       і повідомити про це
  типовий провал:      агент вигадує рецепт або бере калорійність
                       із власних знань


ПАСТКА P2

  question:  Додай плов у мій список покупок
  expected:  відмова: робота зі списком покупок недоступна

  у чому пастка:      серед трьох інструментів немає роботи
                      зі списком покупок
  правильна поведінка: пояснити, що агент уміє лише шукати рецепти,
                       дивитися довідник продуктів і перераховувати порції
  типовий провал:      агент відповідає «додано до списку»,
                       тобто звітує про дію, якої не було
