1.1. КОРПУС

Каталог: data/corpus/
Вміст:   описи моделей ноутбуків, по одному файлу .txt на модель

Структура запису:
  - перший рядок: назва моделі
  - другий рядок: призначення
  - далі: 2-3 речення про сильні та слабкі сторони

Промпт для генерації (надішліть чат-боту):

    Згенеруй 12 описів вигаданих моделей ноутбуків для навчального
    проєкту. Назви моделей теж вигадані, реальні бренди не використовуй.

    Формат кожного опису:
    - перший рядок: назва моделі латиницею, наприклад StudyBook 14
    - другий рядок: призначення
    - далі 2-3 речення про сильні та слабкі сторони

    Вимоги до набору:
    - призначення: навчання, програмування, ігри, дизайн, офіс
    - дві моделі зі схожими назвами
    - одна модель для навчання
    - жодної моделі для монтажу відео 8К

    Видай кожен опис окремим пронумерованим блоком.

Приклад файлу data/corpus/l01.txt:

    StudyBook 14
    Навчання, офісна робота.
    Легкий, тримає заряд до 10 годин, тиха система охолодження.
    Слабка відеокарта, для ігор не підходить.


1.2. ДОВІДНИК

Файл: data/laptops.csv

Колонки:
  - model             назва моделі
  - price             ціна, грн
  - in_stock          кількість на складі
  - warranty_months   гарантія, місяців

Промпт для генерації:

    Ось назви моделей:
    [вставте перші рядки всіх файлів свого корпусу]

    Склади CSV-таблицю з колонками:
    model, price, in_stock, warranty_months

    Пояснення колонок:
    - model: назва моделі, дослівно як у списку вище
    - price: ціле число від 15000 до 90000
    - in_stock: ціле число від 0 до 10
    - warranty_months: 12, 24 або 36

    Вимоги:
    - назви мають збігатися зі списком посимвольно
    - одна модель зі списку має бути ВІДСУТНЯ в таблиці
    - в однієї моделі in_stock = 0

    Видай чистий CSV без пояснень і без markdown-розмітки.

Приклад data/laptops.csv:

    model,price,in_stock,warranty_months
    StudyBook 14,24000,3,12
    CodeMaster Pro,52000,1,24

2. ВИХІДНИЙ КОД ІНСТРУМЕНТІВ
========================================================================

Скопіюйте цей код у файл tools.py без змін.

    import csv
    import os


    def search_laptops(query: str) -> str:
        q = query.lower()
        found = []
        folder = "data/corpus"
        for filename in sorted(os.listdir(folder)):
            with open(os.path.join(folder, filename), encoding="utf-8") as f:
                text = f.read()
            if q in text.lower():
                found.append(text.split("\n")[0])
        if not found:
            return f"За запитом '{query}' нічого не знайдено."
        return " | ".join(found)


    def laptop_info(model: str) -> str:
        with open("data/laptops.csv", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                if row["model"].lower() == model.lower():
                    return (f"Ціна: {row['price']} грн, "
                            f"на складі: {row['in_stock']} шт., "
                            f"гарантія: {row['warranty_months']} міс.")
        return f"Моделі '{model}' немає в довіднику."


    def calc_installment(price: float, months: float,
                         overpay_percent: float) -> str:
        if months <= 0:
            return "Помилка: кількість місяців має бути більшою за нуль."
        total = price * (1 + overpay_percent / 100)
        return (f"{round(total / months, 2)} грн на місяць, "
                f"усього {round(total, 2)} грн")


Реєстр інструментів складаєте самостійно (крок 2 методичних вказівок).

3. ДАНІ ДЛЯ ОПИСІВ ІНСТРУМЕНТІВ
========================================================================

На основі цих відомостей складіть SCHEMAS у файлі schemas.py
(крок 3 методичних вказівок). Готових словників тут немає навмисно:
від того, як ви сформулюєте опис, залежатиме поведінка агента.


ІНСТРУМЕНТ 1

  назва:                search_laptops
  що робить:            шукає ноутбуки за призначенням
                        або характеристикою
  що повертає:          назви знайдених моделей одним рядком
  коли використовувати: користувач описує, для чого потрібен ноутбук,
                        але не називає модель

  аргумент query
    тип:                string
    обов'язковий:       так
    що передавати:      призначення або характеристика, одне-два
                        слова українською, не все питання користувача


ІНСТРУМЕНТ 2

  назва:                laptop_info
  що робить:            шукає модель у довіднику
  що повертає:          ціну, кількість на складі та гарантію
  коли використовувати: модель уже обрано, наприклад її щойно
                        повернув search_laptops

  аргумент model
    тип:                string
    обов'язковий:       так
    що передавати:      точна назва моделі, як вона записана
                        в довіднику


ІНСТРУМЕНТ 3

  назва:                calc_installment
  що робить:            обчислює щомісячний платіж при розстрочці
  що повертає:          суму на місяць і загальну суму
  коли використовувати: завжди, коли треба порахувати розстрочку;
                        самостійно модель не рахує

  аргумент price
    тип:                number
    обов'язковий:       так
    що передавати:      ціна товару, отримана з довідника

  аргумент months
    тип:                number
    обов'язковий:       так
    що передавати:      кількість місяців розстрочки

  аргумент overpay_percent
    тип:                number
    обов'язковий:       так
    що передавати:      переплата за весь строк у відсотках;
                        якщо переплати немає, передавай 0

ЗАДАЧА Z1

  потрібно інструментів: 1 (search_laptops)


ЗАДАЧА Z2

  question:  Порадь ноутбук для навчання і скажи, чи є він

  expected:  назва моделі, ціна та кількість на складі
  потрібно інструментів: 2 (search_laptops, потім laptop_info)

  не обрано, нема чого шукати в довіднику.


ЗАДАЧА Z3

  question:  Порадь ноутбук для навчання і скажи, скільки платити
             на місяць при розстрочці на 6 місяців з переплатою 10%
  expected:  назва моделі та щомісячний платіж
  потрібно інструментів: 3 (search_laptops, laptop_info,
                            calc_installment)

  Ключова задача варіанта. Кожен наступний крок спирається
  на результат попереднього.


ПАСТКА P1

  question:  Порадь ноутбук для монтажу відео 8К
  expected:  повідомлення, що такої моделі немає

  у чому пастка:      у корпусі немає моделей для відео 8К
  правильна поведінка: викликати пошук, отримати порожній результат
                       і повідомити про це
  типовий провал:      агент вигадує модель або радить реальний бренд
                       з власних знань


ПАСТКА P2

  question:  Зарезервуй мені цей ноутбук
  expected:  відмова: резервування недоступне

  у чому пастка:      серед трьох інструментів немає резервування
  правильна поведінка: пояснити, що агент уміє лише підбирати моделі,
                       повідомляти ціну й рахувати розстрочку
  типовий провал:      агент відповідає «ноутбук зарезервовано»,
                       тобто звітує про дію, якої не було
