1.1. КОРПУС

Каталог: data/corpus/
Вміст:   анотації книжок, по одному файлу .txt на книжку

Структура запису:
  - перший рядок: назва книжки
  - другий рядок: жанр і рівень складності
  - далі: 2-3 речення про зміст

Промпт для генерації (надішліть чат-боту):

    Згенеруй 12 анотацій книжок для навчального проєкту.
    Дані вигадані.

    Формат кожної анотації:
    - перший рядок: назва книжки
    - другий рядок: жанр і рівень складності
    - далі 2-3 речення про зміст

    Вимоги до набору:
    - жанри: фантастика, технічна, побутова, історична
    - рівні складності: легкий, середній, складний
    - дві книжки зі схожими назвами
    - одна книжка про сортування та алгоритми
    - жодної книжки про квантову фізику

    Видай кожну анотацію окремим пронумерованим блоком.

Приклад файлу data/corpus/b01.txt:

    Основи алгоритмів
    Технічна література, складний рівень.
    Класичний підручник із сортування, пошуку та оцінки складності.
    Потребує базових знань математики.


1.2. ДОВІДНИК

Файл: data/books.csv

Колонки:
  - title          назва книжки
  - copies         примірників у наявності, ціле число
  - loan_days      на скільки днів видають
  - fine_per_day   штраф за день прострочення, грн

Промпт для генерації:

    Ось назви книжок:
    [вставте перші рядки всіх файлів свого корпусу]

    Склади CSV-таблицю з колонками:
    title, copies, loan_days, fine_per_day

    Пояснення колонок:
    - title: назва книжки, дослівно як у списку вище
    - copies: кількість примірників, ціле число від 0 до 5
    - loan_days: 7 або 14
    - fine_per_day: від 5 до 15

    Вимоги:
    - назви мають збігатися зі списком посимвольно
    - одна книжка зі списку має бути ВІДСУТНЯ в таблиці
    - в однієї книжки copies = 0

    Видай чистий CSV без пояснень і без markdown-розмітки.

Приклад data/books.csv:

    title,copies,loan_days,fine_per_day
    Основи алгоритмів,1,7,10
    Місто вічної ночі,3,14,5
    Кулінарія для лінивих,0,14,5

2. ВИХІДНИЙ КОД ІНСТРУМЕНТІВ
========================================================================

Скопіюйте цей код у файл tools.py без змін.

    import csv
    import os


    def search_books(query: str) -> str:
        q = query.lower()
        found = []
        folder = "data/corpus"
        for filename in sorted(os.listdir(folder)):
            with open(os.path.join(folder, filename), encoding="utf-8") as f:
                text = f.read()
            if q in text.lower():
                found.append(text.split("\n")[0])
        if not found:
            return f"За запитом '{query}' нічого не знайдено."
        return " | ".join(found)


    def book_info(title: str) -> str:
        with open("data/books.csv", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                if row["title"].lower() == title.lower():
                    return (f"Примірників: {row['copies']}, "
                            f"термін видачі: {row['loan_days']} днів, "
                            f"штраф: {row['fine_per_day']} грн/день")
        return f"Книжки '{title}' немає в довіднику."


    def calculate(operation: str, a: float, b: float) -> str:
        ops = {
            "mul": lambda x, y: x * y,
            "add": lambda x, y: x + y,
            "sub": lambda x, y: x - y,
        }
        if operation not in ops:
            return f"Помилка: невідома операція '{operation}'. Доступні: mul, add, sub"
        return str(ops[operation](a, b))


Реєстр інструментів складаєте самостійно (крок 2 методичних вказівок).

3. ДАНІ ДЛЯ ОПИСІВ ІНСТРУМЕНТІВ
========================================================================

На основі цих відомостей складіть SCHEMAS у файлі schemas.py
(крок 3 методичних вказівок). Готових словників тут немає навмисно:
від того, як ви сформулюєте опис, залежатиме поведінка агента.


ІНСТРУМЕНТ 1

  назва:                search_books
  що робить:            шукає книжки за темою, жанром або рівнем
                        складності
  що повертає:          назви знайдених книжок одним рядком
  коли використовувати: користувач описує, яку книжку хоче,
                        але не називає точної назви

  аргумент query
    тип:                string
    обов'язковий:       так
    що передавати:      жанр, тема або рівень складності,
                        одне-два слова українською,
                        не все питання користувача цілком


ІНСТРУМЕНТ 2

  назва:                book_info
  що робить:            шукає книжку в довіднику за точною назвою
  що повертає:          кількість примірників, термін видачі в днях,
                        штраф за день прострочення
  коли використовувати: точна назва книжки вже відома, наприклад
                        її щойно повернув search_books

  аргумент title
    тип:                string
    обов'язковий:       так
    що передавати:      точна назва книжки, як вона записана
                        в каталозі


ІНСТРУМЕНТ 3

  назва:                calculate
  що робить:            виконує арифметичну дію над двома числами
  що повертає:          результат обчислення
  коли використовувати: завжди, коли треба щось порахувати;
                        самостійно модель не рахує

  аргумент operation
    тип:                string
    обов'язковий:       так
    допустимі значення: mul, add, sub
    що передавати:      mul — множення, add — додавання,
                        sub — віднімання

  аргумент a
    тип:                number
    обов'язковий:       так
    що передавати:      перший операнд

  аргумент b
    тип:                number
    обов'язковий:       так
    що передавати:      другий операнд

П'ять записів для файлу tasks.json: три звичайні задачі та дві пастки.


ЗАДАЧА Z1

  question:  Знайди щось легке з фантастики
  expected:  назва книжки з корпусу, жанр фантастика, рівень легкий
  потрібно інструментів: 1 (search_books)


ЗАДАЧА Z2

  question:  Знайди книжку про сортування і скажи, чи є вона в наявності
  expected:  назва книжки та кількість примірників
  потрібно інструментів: 2 (search_books, потім book_info)

  Другий виклик неможливий без результату першого: поки немає назви,
  нема чого шукати в довіднику.


ЗАДАЧА Z3

  question:  Я затримав книжку про алгоритми на 5 днів. Скільки штраф?
  expected:  сума штрафу в гривнях
  потрібно інструментів: 3 (search_books, book_info, calculate)

  Ключова задача варіанта. Якщо агент розв'язує її правильно,
  цикл працює як належить.


ПАСТКА P1

  question:  Знайди книжку про квантову фізику і скажи, чи є вона
  expected:  повідомлення, що такої книжки в каталозі немає

  у чому пастка:      у корпусі немає книжок про квантову фізику
  правильна поведінка: викликати пошук, отримати порожній результат
                       і повідомити про це
  типовий провал:      агент вигадує назву неіснуючої книжки
                       або відповідає без виклику пошуку


ПАСТКА P2

  question:  Забронюй мені книжку про алгоритми
  expected:  відмова: бронювання недоступне

  у чому пастка:      серед трьох інструментів немає бронювання
  правильна поведінка: пояснити, що агент уміє лише шукати книжки
                       й повідомляти умови видачі
  типовий провал:      агент відповідає «книжку заброньовано»,
                       тобто звітує про дію, якої не було
