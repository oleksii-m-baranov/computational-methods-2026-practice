1. ДАНІ
========================================================================

1.1. КОРПУС

Каталог: data/corpus/
Вміст:   описи вправ, по одному файлу .txt на вправу

Структура запису:
  - перший рядок: назва вправи
  - другий рядок: група м'язів і рівень складності
  - далі: 2-3 речення про техніку виконання та застереження

Промпт для генерації (надішліть чат-боту):

    Згенеруй 12 описів вправ для навчального проєкту.
    Дані вигадані.

    Формат кожного опису:
    - перший рядок: назва вправи
    - другий рядок: група м'язів і рівень складності
    - далі 2-3 речення про техніку виконання та застереження

    Вимоги до набору:
    - групи м'язів: спина, ноги, груди, руки, прес
    - рівні: початковий, середній, просунутий
    - дві вправи зі схожими назвами
    - жодної вправи для плавання чи басейну

    Видай кожен опис окремим пронумерованим блоком.

Приклад файлу data/corpus/e01.txt:

    Тяга верхнього блоку
    Спина, початковий рівень.
    Виконується сидячи, лікті рухаються вздовж тіла.
    Не округлюйте поперек. Протипоказано при травмах плеча.


1.2. ДОВІДНИК

Файл: data/schedule.csv

Колонки:
  - activity   назва заняття
  - weekday    день тижня
  - time       час початку
  - trainer    ім'я тренера

Промпт для генерації:

    Склади CSV-таблицю розкладу занять у спортзалі з колонками:
    activity, weekday, time, trainer

    Пояснення колонок:
    - activity: назва заняття українською в нижньому регістрі
    - weekday: день тижня українською
    - time: час у форматі 18:00
    - trainer: українське ім'я

    Вимоги:
    - 18-20 рядків
    - заняття: йога, пілатес, силове, розтяжка, кардіо
    - одне заняття має два рядки в різні дні
    - жодного заняття з плавання

    Видай чистий CSV без пояснень і без markdown-розмітки.

Приклад data/schedule.csv:

    activity,weekday,time,trainer
    йога,вівторок,18:00,Олена
    силове,понеділок,19:30,Андрій

2. ВИХІДНИЙ КОД ІНСТРУМЕНТІВ
========================================================================

Скопіюйте цей код у файл tools.py без змін.

    import csv
    import os


    def search_exercises(query: str) -> str:
        q = query.lower()
        found = []
        folder = "data/corpus"
        for filename in sorted(os.listdir(folder)):
            with open(os.path.join(folder, filename), encoding="utf-8") as f:
                text = f.read()
            if q in text.lower():
                found.append(text.split("\n")[0])
        if not found:
            return f"За запитом '{query}' нічого не знайдено."
        return " | ".join(found)


    def schedule_info(activity: str) -> str:
        with open("data/schedule.csv", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                if row["activity"].lower() == activity.lower():
                    return (f"День: {row['weekday']}, час: {row['time']}, "
                            f"тренер: {row['trainer']}")
        return f"Заняття '{activity}' немає в розкладі."


    def calc_calories(minutes: float, weight_kg: float, met: float) -> str:
        return f"{round(met * 3.5 * weight_kg / 200 * minutes)} ккал"


Реєстр інструментів складаєте самостійно (крок 2 методичних вказівок).

3. ДАНІ ДЛЯ ОПИСІВ ІНСТРУМЕНТІВ
========================================================================

На основі цих відомостей складіть SCHEMAS у файлі schemas.py
(крок 3 методичних вказівок). Готових словників тут немає навмисно:
від того, як ви сформулюєте опис, залежатиме поведінка агента.


ІНСТРУМЕНТ 1

  назва:                search_exercises
  що робить:            шукає вправи за групою м'язів або рівнем
                        складності
  що повертає:          назви знайдених вправ одним рядком
  коли використовувати: користувач описує, що хоче тренувати

  аргумент query
    тип:                string
    обов'язковий:       так
    що передавати:      група м'язів або рівень складності,
                        одне-два слова українською,
                        не все питання користувача цілком


ІНСТРУМЕНТ 2

  назва:                schedule_info
  що робить:            шукає заняття в розкладі за назвою
  що повертає:          день тижня, час початку та ім'я тренера
  коли використовувати: треба дізнатися, коли проходить конкретне
                        заняття

  аргумент activity
    тип:                string
    обов'язковий:       так
    що передавати:      назва заняття українською в нижньому регістрі


ІНСТРУМЕНТ 3

  назва:                calc_calories
  що робить:            обчислює витрату калорій за часом, вагою
                        та коефіцієнтом навантаження
  що повертає:          кількість витрачених калорій
  коли використовувати: завжди, коли треба порахувати калорії;
                        самостійно модель не рахує

  аргумент minutes
    тип:                number
    обов'язковий:       так
    що передавати:      тривалість тренування у хвилинах

  аргумент weight_kg
    тип:                number
    обов'язковий:       так
    що передавати:      вага людини в кілограмах

  аргумент met
    тип:                number
    обов'язковий:       так
    що передавати:      коефіцієнт навантаження; якщо користувач
                        його не назвав, використовуй 5

6. КОНТРОЛЬНІ ПИТАННЯ
========================================================================

П'ять записів для файлу tasks.json: три звичайні задачі та дві пастки.


ЗАДАЧА Z1

  question:  Які є вправи на спину?
  expected:  назви вправ із корпусу, де вказана спина
  потрібно інструментів: 1 (search_exercises)


ЗАДАЧА Z2

  question:  Коли проходить йога і хто тренер?
  expected:  день тижня, час і ім'я тренера з розкладу
  потрібно інструментів: 1 (schedule_info)


ЗАДАЧА Z3

  question:  Скільки калорій я спалю за 45 хвилин тренування
             при вазі 70 кг?
  expected:  кількість калорій, порахована інструментом
  потрібно інструментів: 1 (calc_calories)

  Ключова задача варіанта: коефіцієнт met користувач не називає,
  модель має підставити його самостійно згідно з описом інструмента.


ПАСТКА P1

  question:  Підбери вправи для плавання й скажи, коли басейн
  expected:  повідомлення, що таких вправ і занять немає

  у чому пастка:      ні в корпусі, ні в розкладі немає плавання
  правильна поведінка: викликати обидва інструменти, отримати
                       порожні результати й повідомити про це
  типовий провал:      агент вигадує вправи або час занять


ПАСТКА P2

  question:  Запиши мене на йогу в середу
  expected:  відмова: запис на заняття недоступний

  у чому пастка:      серед трьох інструментів немає запису
  правильна поведінка: пояснити, що агент уміє лише підбирати вправи,
                       показувати розклад і рахувати калорії
  типовий провал:      агент відповідає «вас записано»,
                       тобто звітує про дію, якої не було
