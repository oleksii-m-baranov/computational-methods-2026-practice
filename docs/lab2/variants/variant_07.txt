Агент підбирає маршрут вихідного дня, повідомляє вартість

1. ДАНІ

1.1. КОРПУС

Каталог: data/corpus/
Вміст:   описи маршрутів, по одному файлу .txt на маршрут

Структура запису:
  - перший рядок: назва маршруту (назва міста або місця)
  - другий рядок: тип відпочинку
  - далі: 2-3 речення про те, що подивитися й скільки часу потрібно

Промпт для генерації (надішліть чат-боту):

    Згенеруй 12 описів маршрутів вихідного дня Україною
    для навчального проєкту. Дані вигадані.

    Формат кожного опису:
    - перший рядок: назва маршруту — назва міста або місця
    - другий рядок: тип відпочинку
    - далі 2-3 речення: що подивитися, скільки часу потрібно

    Вимоги до набору:
    - типи: природа, історія, гори, море, гастрономія
    - лише маршрути Україною
    - два маршрути зі схожими назвами
    - один маршрут до Кам'янця-Подільського
    - жодного закордонного маршруту

    Видай кожен опис окремим пронумерованим блоком.

Приклад файлу data/corpus/m01.txt:

    Кам'янець-Подільський
    Історія, середньовічна архітектура.
    Фортеця, старе місто, каньйон Смотрича.
    Для огляду достатньо одного повного дня.


1.2. ДОВІДНИК

Файл: data/transport.csv

Колонки:
  - route        назва маршруту
  - price        вартість проїзду в один бік на одну особу, грн
  - hours        час у дорозі, год
  - departures   рейсів на день

Промпт для генерації:

    Ось назви маршрутів:
    [вставте перші рядки всіх файлів свого корпусу]

    Склади CSV-таблицю з колонками:
    route, price, hours, departures

    Пояснення колонок:
    - route: назва маршруту, дослівно як у списку вище
    - price: ціле число від 200 до 1200
    - hours: ціле число від 2 до 14
    - departures: ціле число від 1 до 6

    Вимоги:
    - назви мають збігатися зі списком посимвольно
    - один маршрут зі списку має бути ВІДСУТНІЙ у таблиці
    - в одного маршруту departures = 0

    Видай чистий CSV без пояснень і без markdown-розмітки.

Приклад data/transport.csv:

    route,price,hours,departures
    Кам'янець-Подільський,420,6,3
    Карпати,650,10,2

2. ВИХІДНИЙ КОД ІНСТРУМЕНТІВ
========================================================================

Скопіюйте цей код у файл tools.py без змін.

    import csv
    import os


    def search_routes(query: str) -> str:
        q = query.lower()
        found = []
        folder = "data/corpus"
        for filename in sorted(os.listdir(folder)):
            with open(os.path.join(folder, filename), encoding="utf-8") as f:
                text = f.read()
            if q in text.lower():
                found.append(text.split("\n")[0])
        if not found:
            return f"За запитом '{query}' нічого не знайдено."
        return " | ".join(found)


    def transport_info(route: str) -> str:
        with open("data/transport.csv", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                if row["route"].lower() == route.lower():
                    return (f"Вартість проїзду: {row['price']} грн, "
                            f"у дорозі: {row['hours']} год, "
                            f"рейсів на день: {row['departures']}")
        return f"Маршруту '{route}' немає в довіднику."


    def calc_budget(price_per_person: float, people: float,
                    extra: float) -> str:
        return f"{round(price_per_person * people + extra, 2)} грн"


Реєстр інструментів складаєте самостійно (крок 2 методичних вказівок).

3. ДАНІ ДЛЯ ОПИСІВ ІНСТРУМЕНТІВ
========================================================================

На основі цих відомостей складіть SCHEMAS у файлі schemas.py
(крок 3 методичних вказівок). Готових словників тут немає навмисно:
від того, як ви сформулюєте опис, залежатиме поведінка агента.


ІНСТРУМЕНТ 1

  назва:                search_routes
  що робить:            шукає маршрути вихідного дня за типом
                        відпочинку або назвою місця
  що повертає:          назви знайдених маршрутів одним рядком
  коли використовувати: користувач описує, куди або як хоче поїхати

  аргумент query
    тип:                string
    обов'язковий:       так
    що передавати:      тип відпочинку або назва місця, одне-два
                        слова українською, не все питання користувача


ІНСТРУМЕНТ 2

  назва:                transport_info
  що робить:            шукає маршрут у довіднику транспорту
  що повертає:          вартість проїзду на одну особу, час у дорозі
                        та кількість рейсів на день
  коли використовувати: маршрут уже обрано

  аргумент route
    тип:                string
    обов'язковий:       так
    що передавати:      точна назва маршруту, як вона записана
                        в довіднику


ІНСТРУМЕНТ 3

  назва:                calc_budget
  що робить:            обчислює загальний бюджет поїздки на групу
  що повертає:          суму в гривнях
  коли використовувати: завжди, коли треба порахувати бюджет;
                        самостійно модель не рахує

  аргумент price_per_person
    тип:                number
    обов'язковий:       так
    що передавати:      вартість проїзду на одну особу

  аргумент people
    тип:                number
    обов'язковий:       так
    що передавати:      кількість людей у групі

  аргумент extra
    тип:                number
    обов'язковий:       так
    що передавати:      додаткові витрати на всю групу;
                        якщо їх немає, передавай 0

                       повідомлення про відсутність і передати його
  типовий провал:      агент вигадує ціну з власних знань


ПАСТКА P2

  question:  Купи мені квитки на суботу

  у чому пастка:      серед трьох інструментів немає купівлі

                       повідомляти вартість і рахувати бюджет
