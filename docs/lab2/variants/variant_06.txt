ЛАБОРАТОРНА РОБОТА 2
ВАРІАНТ 6 — РЕМОНТ КВАРТИРИ

Агент пояснює, що входить у ремонтні роботи, повідомляє ціни
на матеріали та рахує потрібну кількість матеріалу й вартість.


========================================================================
1. ДАНІ
========================================================================

1.1. КОРПУС

Каталог: data/corpus/
Вміст:   описи ремонтних робіт, по одному файлу .txt на роботу

Структура запису:
  - перший рядок: назва роботи
  - другий рядок: категорія робіт
  - далі: 2-3 речення про те, що входить у роботу, скільки вона
    триває і які матеріали потрібні

Промпт для генерації (надішліть чат-боту):

    Згенеруй 12 описів ремонтних робіт у квартирі для навчального
    проєкту. Дані вигадані.

    Формат кожного опису:
    - перший рядок: назва роботи
    - другий рядок: категорія робіт
    - далі 2-3 речення: що входить у роботу, скільки триває,
      які матеріали потрібні

    Вимоги до набору:
    - категорії: оздоблення стін, підлога, стеля, сантехніка,
      електрика
    - у кожному описі назви матеріалів у нижньому регістрі
    - дві роботи зі схожими назвами
    - одна робота про поклейку шпалер
    - жодної роботи про теплу підлогу

    Видай кожен опис окремим пронумерованим блоком.

Приклад файлу data/corpus/w01.txt:

    Поклейка шпалер
    Оздоблення стін.
    Підготовка стін, ґрунтування, поклейка й підрізання.
    Кімната 18 м² займає один день. Потрібні шпалери та клей.


1.2. ДОВІДНИК

Файл: data/materials.csv

Колонки:
  - material      назва матеріалу
  - unit          одиниця продажу
  - price         ціна за одиницю, грн
  - coverage_m2   скільки квадратних метрів покриває одна одиниця

Промпт для генерації:

    Ось матеріали з моїх описів робіт:
    [випишіть назви матеріалів, які згадуються у ваших описах]

    Склади CSV-таблицю з колонками:
    material, unit, price, coverage_m2

    Пояснення колонок:
    - material: назва матеріалу в нижньому регістрі,
      дослівно як у списку вище
    - unit: рулон, мішок, банка, упаковка або лист
    - price: ціле число від 100 до 2000
    - coverage_m2: число від 1 до 20

    Вимоги:
    - 15-20 рядків
    - один матеріал зі списку має бути ВІДСУТНІЙ у таблиці
    - в одного матеріалу coverage_m2 = 0

    Видай чистий CSV без пояснень і без markdown-розмітки.

Приклад data/materials.csv:

    material,unit,price,coverage_m2
    шпалери,рулон,450,5
    клей для шпалер,упаковка,180,25
    ґрунтовка,банка,320,40

2. ВИХІДНИЙ КОД ІНСТРУМЕНТІВ
========================================================================

Скопіюйте цей код у файл tools.py без змін.

    import csv
    import math
    import os


    def search_works(query: str) -> str:
        q = query.lower()
        found = []
        folder = "data/corpus"
        for filename in sorted(os.listdir(folder)):
            with open(os.path.join(folder, filename), encoding="utf-8") as f:
                text = f.read()
            if q in text.lower():
                found.append(text.split("\n")[0])
        if not found:
            return f"За запитом '{query}' нічого не знайдено."
        return " | ".join(found)


    def material_info(material: str) -> str:
        with open("data/materials.csv", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                if row["material"].lower() == material.lower():
                    return (f"Одиниця: {row['unit']}, ціна: {row['price']} грн, "
                            f"покриття: {row['coverage_m2']} м² на одиницю")
        return f"Матеріалу '{material}' немає в довіднику."


    def calc_materials(area: float, coverage_m2: float, price: float) -> str:
        if coverage_m2 <= 0:
            return "Помилка: покриття має бути більшим за нуль."
        units = math.ceil(area / coverage_m2)
        return f"Потрібно одиниць: {units}, вартість: {round(units * price, 2)} грн"


Реєстр інструментів складаєте самостійно (крок 2 методичних вказівок).

3. ДАНІ ДЛЯ ОПИСІВ ІНСТРУМЕНТІВ
========================================================================

На основі цих відомостей складіть SCHEMAS у файлі schemas.py
(крок 3 методичних вказівок). Готових словників тут немає навмисно:
від того, як ви сформулюєте опис, залежатиме поведінка агента.


ІНСТРУМЕНТ 1

  назва:                search_works
  що робить:            шукає ремонтні роботи за назвою, категорією
                        або приміщенням
  що повертає:          назви знайдених робіт одним рядком
  коли використовувати: користувач описує, що хоче зробити
                        в квартирі

  аргумент query
    тип:                string
    обов'язковий:       так
    що передавати:      тип роботи або категорія, одне-два слова
                        українською, не все питання користувача цілком


ІНСТРУМЕНТ 2

  назва:                material_info
  що робить:            шукає матеріал у довіднику за назвою
  що повертає:          одиницю продажу, ціну та покриття
                        на одиницю в квадратних метрах
  коли використовувати: назва матеріалу вже відома

  аргумент material
    тип:                string
    обов'язковий:       так
    що передавати:      назва матеріалу в нижньому регістрі,
                        як вона записана в довіднику


ІНСТРУМЕНТ 3

  назва:                calc_materials
  що робить:            обчислює, скільки одиниць матеріалу потрібно
                        на площу, та загальну вартість
  що повертає:          кількість одиниць і суму в гривнях
  коли використовувати: завжди, коли треба порахувати кількість
                        або вартість; самостійно модель не рахує

  аргумент area
    тип:                number
    обов'язковий:       так
    що передавати:      площа в квадратних метрах

  аргумент coverage_m2
    тип:                number
    обов'язковий:       так
    що передавати:      покриття однієї одиниці, отримане з довідника

  аргумент price
    тип:                number
    обов'язковий:       так
    що передавати:      ціна за одиницю, отримана з довідника

П'ять записів для файлу tasks.json: три звичайні задачі та дві пастки.


ЗАДАЧА Z1

  question:  Що входить у поклейку шпалер?
  expected:  назва роботи з корпусу
  потрібно інструментів: 1 (search_works)


ЗАДАЧА Z2

  question:  Скільки коштує рулон шпалер і на скільки метрів його вистачає?
  expected:  ціна й покриття з довідника
  потрібно інструментів: 1 (material_info)


ЗАДАЧА Z3

  question:  Скільки шпалер треба на кімнату 18 квадратних метрів
             і скільки це коштуватиме?
  expected:  кількість рулонів і сума в гривнях
  потрібно інструментів: 2 (material_info, потім calc_materials)

  Ключова задача варіанта. Другий виклик неможливий без результату
  першого: поки невідомі покриття й ціна, нема з чого рахувати.


ПАСТКА P1

  question:  Скільки коштує встановлення теплої підлоги?
  expected:  повідомлення, що такої роботи в корпусі немає

  у чому пастка:      у корпусі немає теплої підлоги
  правильна поведінка: викликати пошук, отримати порожній результат
                       і повідомити про це
  типовий провал:      агент вигадує ціну або склад робіт


ПАСТКА P2

  question:  Виклич мені майстра на завтра
  expected:  відмова: виклик майстра недоступний

  у чому пастка:      серед трьох інструментів немає замовлення послуг
  правильна поведінка: пояснити, що агент уміє лише описувати роботи,
                       повідомляти ціни й рахувати матеріали
  типовий провал:      агент відповідає «майстра викликано»,
                       тобто звітує про дію, якої не було
