Регламент роботи головної читальної зали та доступу до електронних ресурсів у книгозбірні Кодекс Оріона

Головна читальна зала Науково-просвітницької книгозбірні Кодекс Оріона облаштована як сучасний простір для індивідуальної наукової праці та опрацювання літератури на місці. Загальна місткість простору становить 78 ергономічних робочих місць, кожне з яких обладнане індивідуальним освітленням, розетками та звукопоглинальними перегородками. Доступ до зали надається за наявності дійсного читацького квитка або тимчасової одноденної перепустки, оформленої на стійці реєстрації.

Для роботи з ліцензійними наукометричними базами даних, цифровим каталогом та повнотекстовими архівами дисертацій у східному крилі зали виділено комп'ютерну зону. Цей сектор налічує 26 стаціонарних комп'ютерних терміналів, підключених до захищеної внутрішньої мережі установи без можливості встановлення стороннього програмного забезпечення. Авторизація за кожною робочою станцією відбувається шляхом введення індивідуального логіна читача та одноразового пароля з чека.

З метою забезпечення рівного доступу всіх дослідників до цифрової інфраструктури в години пікового навантаження діє чітке часове регулювання користування технікою. Максимальна тривалість однієї безперервної робочої сесії за стаціонарним комп'ютерним терміналом становить 135 хвилин. Після автоматичного завершення сеансу користувач може продовжити роботу лише за умови відсутності черги очікування у чергового системного адміністратора зали.

Користувачам електронних ресурсів дозволяється безоплатно зберігати фрагменти оцифрованих довідників та наукових періодичних видань із локального репозитарію на власні флеш-носії. При цьому добовий ліміт безкоштовного вивантаження матеріалів із закритих внутрішніх архівів для одного облікового запису не може перевищувати 43 сторінки. Будь-які зовнішні накопичувачі перед підключенням до термінала проходять обов'язкову перевірку антивірусним сканером під наглядом консультанта.

У разі потреби отримання паперових роздруківок або створення цифрових копій друкованих видань відвідувачі можуть скористатися послугами репрографічного пункту при залі. Вартість високоточного кольорового сканування або лазерного друку одного великоформатного аркуша для креслень чи карт становить 18 гривень. Самостійне фотографування сучасних книг дозволяється лише в беззвучному режимі смартфона та без застосування спалаху, який шкодить паперовій основі.

Особливий порядок обслуговування діє у відокремленому секторі стародруків та цінних історичних рукописів, де підтримується постійний мікроклімат і приглушене освітлення. Протягом однієї робочої зміни досліднику може бути одночасно видано для опрацювання за столом не більше ніж 6 одиниць архівного зберігання. Робота з такими раритетними документами здійснюється виключно на спеціальних оксамитових підставках із обов'язковим використанням бавовняних рукавичок.

Для зручності опрацювання дрібного шрифту, картографічних матеріалів та мікрофільмів відвідувачі можуть тимчасово отримати у чергового бібліотекаря додаткове оптичне обладнання. Видача портативної електронної лупи або професійного графічного планшета здійснюється під зворотну грошову заставу в розмірі 290 гривень. Заставна сума повертається читачеві у повному обсязі одразу після здачі непошкодженого пристрою та перевірки його комплектності працівником зали.

Для власників персональних ноутбуків, планшетів і рідерів на всій території читального простору розгорнуто бездротову мережу передачі даних із шифруванням трафіку. Кожному підключеному гостьовому пристрою гарантується симетрична швидкість виділеного інтернет-каналу на рівні 52 мегабіти на секунду для завантаження наукових даних. Використання мережі для відеоконференцій та прослуховування аудіоматеріалів дозволяється лише при підключенні закритих навушників, щоб зберігати тишу.
